# Zephyr IDE Extension Pack

This extension pack provides a full Zephyr RTOS development experience in VS Code, including IntelliSense, KConfig support, and DeviceTree support.

## Included Extensions

| Extension | Description |
|-----------|-------------|
| [Zephyr IDE](https://marketplace.visualstudio.com/items?itemName=mylonics.zephyr-ide) | Core extension for Zephyr RTOS development — SDK installation, west workspace management, building, flashing, and debugging |
| [Cortex-Debug](https://marketplace.visualstudio.com/items?itemName=marus25.cortex-debug) | ARM Cortex-M GDB debugging support |
| [C/C++ (VS Marketplace) / clangd (Open VSX)](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools) | C/C++ IntelliSense, code navigation, and debugging. On Open VSX, [clangd](https://open-vsx.org/extension/llvm-vs-code-extensions/vscode-clangd) is used instead |
| [CMake](https://marketplace.visualstudio.com/items?itemName=twxs.cmake) | CMake language support |
| [DTS LSP](https://marketplace.visualstudio.com/items?itemName=kylemicallefbonnici.dts-lsp) | DeviceTree Source (DTS) language support |
| [Serial Monitor](https://marketplace.visualstudio.com/items?itemName=ms-vscode.vscode-serial-monitor) | Serial port monitor for communicating with embedded devices (VS Marketplace only) |

> **Note:** When installed from the [Open VSX Registry](https://open-vsx.org/extension/mylonics/zephyr-ide-extension-pack), `clangd` is included instead of the Microsoft C/C++ extension, and the Serial Monitor extension is not included as it is not available on Open VSX.
